# Images Directory

Place your logo and icon images here:

- `onr_logo.png` — Sidebar logo (recommended: 300x100px)
- `onr_icon.png` — Page favicon (recommended: 32x32px)

## Default Behavior

If images are not found, the app will display:
- 🚢 as the page icon
- 🏛️ ONR ITSS as the sidebar text

## Image Guidelines

- Use PNG format for best compatibility
- Keep file sizes under 100KB
- Use transparent backgrounds where possible
- Ensure images are appropriate for government demonstration
